# Prompts Used

## 0. Reusable Master Template
```
ROLE: You are a senior conversion copywriter who specializes in local small-business websites.

CONTEXT:
- Business: [name, type]
- Location: [city/neighborhood]
- Offer: [products/services]
- Audience: [who they are, what they worry about]
- Goal: [walk-ins / bookings / enquiries]
- Differentiators: [3 real facts only]

TASK: Write [specific deliverable].

FORMAT: [sections, headings, word limits]

CONSTRAINTS:
- Plain, simple language (grade 7–8 reading level)
- Benefit-first; one idea per sentence
- No clichés ("we pride ourselves", "passion for excellence")
- Do not invent facts, prices, awards or hours; use [PLACEHOLDER]
- Scannable: short paragraphs, clear headings

VOICE: [3–4 adjectives]. Use: [words]. Avoid: [words].
```

## 1. Homepage Prompt
```
ROLE: Senior conversion copywriter for local small-business websites.
CONTEXT: Maple & Main Café, Portland OR. Specialty coffee, fresh-baked pastries, office catering, private event space. Audience: neighborhood locals, remote workers, office managers. Goal: walk-ins, catering enquiries, event bookings. Differentiators: locally roasted beans, baked fresh each morning, cozy space with free Wi-Fi.
TASK: Write full homepage copy.
FORMAT: Hero (headline ≤10 words, subheadline ≤25 words, primary + secondary button text) · Value proposition (3 benefit blocks) · About snippet (60 words) · Services teaser (3 cards) · Social proof section (use placeholders) · Final CTA band.
CONSTRAINTS: Plain language, benefit-first, no clichés, no invented facts, use [PLACEHOLDER] for unknowns.
VOICE: Warm, unpretentious, community-first. Avoid: "artisanal", "curated", "elevate".
```

## 2. Services Prompt
```
Using the same business context, write a service page description for each: (1) Everyday Café, (2) Office Catering, (3) Private Events. For each: headline, 2-sentence intro, 4 bullet benefits, "Perfect for" line, and a service-specific CTA. Max 120 words per service. Same voice and constraints.
```

## 3. CTA Prompt
```
Write 3 CTA sections: Contact, Booking, Enquiry. Each: headline (≤8 words), supporting line (≤20 words), button text (≤4 words), and a 1-line reassurance under the button (e.g., response time). Offer 2 headline options per section for A/B testing.
```

## 4. Tone Adaptation Prompt
```
Rewrite the homepage hero + one service blurb + one CTA for: (a) hair salon, (b) family dental clinic, (c) digital marketing agency. Keep the benefit-first structure but change vocabulary, formality, and emotional angle to fit each audience. Explain tone choices in one line each.
```

## 5. Refinement Prompt (used after first draft)
```
Review the copy above. 1) Cut any sentence that doesn't help the reader act. 2) Replace vague words with specifics or [PLACEHOLDER]. 3) Check every headline is under its limit. 4) Return the final version only.
```
